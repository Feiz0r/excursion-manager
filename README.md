# Система распределения участников по экскурсиям
## Назначение
Сервис создан для упрощения работы организаторов экскурсий
и участников: помогает вести учёт экскурсий, групп и записей,
распределять участников и сохранять данные между запусками.
## Целевая аудитория
Сервис будет полезен туроператорам, экскурсоводам и участникам экскурсий 
## Предметная область
- планирование экскурсий;
- регистрация участников;
- формирование групп с учётом ограничений;
- запись участников на экскурсии и отмена записей;
- контроль вместимости групп и экскурсий.
## Основные сущности
- участник
- экскурсия
- группа
- Распределение
## Основные функции
- создание, редактирование и удаление экскурсий;
- регистрация, поиск, сортировка и удаление участников;
- создание и удаление групп, привязанных к экскурсиям;
- запись участника на экскурсию с проверкой дубликатов;
- проверка вместимости экскурсии и группы;
- просмотр списков участников, экскурсий, групп и записей;
- отмена записи;
- сохранение и загрузка данных в JSON-файлах.
## Структура проекта
- main.py – точка запуска;
- user.py - работа с участниками;
- excursion.py – работа с экскурсиями;
- group.py – работа с группами;
- enrollment.py – записи и распределение;
- storage.py - сохранение и загрузка JSON
- utils.py - вспомогательные функции ввода
- data/ – JSON-файлы данных;
- tests/ – автоматизированные тесты.
## Требования
- Python 3.x;
- pytest;
- flake8.
