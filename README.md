# Система распределения участников по экскурсиям
## Назначение
Сервис создан для упрощения жизни участиников экскурсий и людей отвественных за формирование групп.
## Целевая аудитория
Сервис будет полезен туроператорам, экскурсоводам и участникам экскурсий 
## Предметная область
- планирование мероприятий
- регистрацию участников
- формирование групп с учётом ограничений
- контроль записи и отмен
## Основные сущности
- участник
- экскурсия
- группа
- Распределение
## Основные функции
- создание экскурсии
- редактирование и отмена экскурсии
- регистрация участника
- запись участника на экскурсию
- проверка вместимости и ограничений
- просмотр списков групп и участников
- автоматическое и ручное распределение участников по группам
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
